# LujanDev Orbit — Brand Assets

Identidad aprobada: núcleo + dos trayectorias + tres nodos. El favicon elimina los nodos externos para legibilidad a 16 px.

## Archivos
- `orbit-logo-horizontal.svg`: navbar y cabeceras (fondo transparente).
- `orbit-logo-stacked.svg`: composición vertical (fondo transparente).
- `orbit-symbol.svg`: isotipo completo (fondo transparente).
- `orbit-favicon.svg`: isotipo simplificado sobre fondo oscuro.
- `favicon-16x16.png`, `favicon-32x32.png`: favicons.
- `apple-touch-icon.png`: icono 180×180.
- `orbit-icon-192.png`, `orbit-icon-512.png`: iconos de aplicación.
- `orbit-logo-horizontal-preview.png`: vista previa.

## Paleta
- Fondo: `#0d1017`
- Azul: `#3b82f6`
- Violeta: `#6d00d9`
- Texto: `#f5f7fa`

Los SVG son vectoriales y editables. La tipografía utiliza fuentes de sistema (Arial/Helvetica) para no incluir archivos de fuentes. La disponibilidad de la fuente puede variar entre sistemas.

## Integración sugerida en Angular
Copiar los recursos a `src/assets/brand/orbit/`. No sustituir el favicon ni el HTML antes de revisar la configuración actual de `angular.json` y `src/index.html`.
